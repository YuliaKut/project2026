🏛️ Il Tesoro dei Medici – Project Documentation

1. Exhibition Overview

“Il Tesoro dei Medici” was an exhibition held in Moscow in 2011. It ran from 20 May to 1 August 2011 and was organized as part of the cultural exchanges between Italy and Russia.

The exhibition presented the extraordinary decorative-art collection of the Medici family, the dynasty that ruled Florence and Tuscany during the Renaissance. The works came mainly from the Medici collections preserved in Florence.

The show focused not on paintings, but on the Medici passion for luxury objects and collecting, including jewellery, gold and silver works, and artistic objects that demonstrated the family’s wealth, taste, and political power.

A major theme of the exhibition was how the Medici used collecting as a way to express Renaissance ideals of culture, magnificence, and authority. The treasures reflected the tastes of rulers such as Cosimo I de' Medici and later members of the dynasty, including the final Medici heir Anna Maria Luisa de' Medici.

2. SPARQL Queries & Results

The following queries were used to explore the ArCo knowledge graph and retrieve information about cultural events in Russia.

Query 1: Events in Moscow

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#> PREFIX clv: <https://w3id.org/italia/onto/CLV/> PREFIX cis: <http://dati.beniculturali.it/cis/> SELECT * WHERE { ?place a cis:GeographicalFeature ; rdfs:label "Mosca" . ?event a cis:CulturalEvent ; clv:hasSpatialCoverage ?place ; rdfs:label ?eventLabel } ORDER BY DESC(?eventLabel) LIMIT 100

Description: Since we have decided to work on the events combining Russian and Italian cultural heritage, the initial first step is choosing an event.

The main cities to consider in Russia are Moscow and Saint-Petersburg. The query for Saint-Petersburg (rdfs:label "Pietroburgo") has shown only one event (link 1) held in 1902, while the query for Moscow (rdfs:label "Mosca") has shown much more options (link 2). My choice was "Il Tesoro dei Medici", 2011, since a) it is a modern event and it is easier to find relevant information about it; b) ... .

Query 2: Describe Event IRI

PREFIX cis: <https://w3id.org/arco/resource/CulturalEvent/> DESCRIBE cis:4c88dc5e0662f98f9c0ff26a0b51e4d3

Description: The first thing needed to be done is to determine the information about my event that is already present in the ArCo. Exploring the KG's ontology, we are able to identify and use classes and properties that can be used to model a needed query.

The task can be done in a couple of ways. For instance, on the left I have provided SPARQL-query requesting all the information available about the event in the form of microdata document. Along with the place, name (rdfs:label OR l0:name) and the date (tiapit:time) of my event, I have successfully found the information about the type of the event (rdf:type) and a cultural entity involved – unfortunately, only one entity is presented in the microdata document (cis:involvesCulturalEntity) (link 3).

However, by comparing the events held in different cities, we can assume that for each of them the pieces of information indicated are these:

  • a) name of the event (rdfs:label OR l0:name);
  • b) type of the event (rdf:type);
  • c) paintings, sculptures, other masterpieces presented (cis:involvesCulturalEntity);
  • d) date of the event (ti:time).
Usually these features are the only ones presented on the IRI of an event. Thus, a lot of information is missing.

Query 3: All Properties of the Event

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#> SELECT ?property ?value ?valueLabel WHERE { <https://w3id.org/arco/resource/CulturalEvent/4c88dc5e0662f98f9c0ff26a0b51e4d3> ?property ?value . OPTIONAL { ?value rdfs:label ?valueLabel . } }

Description: However, I wanted to focus on two specific missing things for my event. When I have checked via SPARQL whether they exist, the answer from ArCo made it clear they are not presented in the KG. Those things are as following:
a) what museum held my event in Moscow (e.g., through clv:hasSpatialCoverage) – no response, empty table;
b) who has organised my event (e.g., through "arco:hasEventOrganiser ?organiser") – no response, empty table.

Checking the results with the SPARQL-query that allows us to see all the features of the specific event (provided on the left, plus see link 4), we receive the proof ArCo misses the specific place of the event and its organisers. Those are the problems we are focusing on.

3. Using AI Tools to Enrich the Knowledge Graph

Step 1: Questions

Prompt for the LLMs:
"Provide me with necessary information on 'Il Tesoro dei Medici'. Provide me with the answer as following: 1) the date of the event; 2) the place of the event – country, city, museum; 3) the organisers of the event. The date of the event is being asked to avoid the possibility of events with the same name appearing."

Step 2: Answers

🤖 ChatGPT

Response: (pic. 1) Despite the format prompting, the LLM has given a lot of context on the event, thus "opening a dialogue" with the user. However, the tool managed to provide with necessary information, immediately indicating reliable sources.

🟣 Pi AI

Response: (pic. 2) The tool has not proven to be "the first emotionally intelligent AI" since it lacks the hooks to encourage communication with the user. What is even more important, is the fact of Pi AI providing false information about the event, not considering the possibility of several events with the same name existing.

Conclusion: The conclusion we can draw from the both responses is that ChatGPT, although adding too much context to its replies, is more reliable LLM and will be used for this project. For less reliable AI tools, the more detailed engineering of the initial prompt is required. It includes providing more information about the event in the prompt hence avoiding the target event being mixed up with any other one holding the same name.

5. Summary

To sum up, using AI tools and the ontology of ArCo, we were able not only to investigate the weak points of the knowledge graph and lack of specific pieces of information, but also to successfully solve these problems, thus enriching the ArCo's ontology with two new triplets:

  • a) Il Tesoro dei Medici – hasSpatialCoverage – the Kremlin Museums
  • b) Gallerie degli Uffizi – isEventOrganiserof – Il Tesoro dei Medici
    OR
    Il Tesoro dei Medici – hasEventOrganiser – Gallerie degli Uffizi
